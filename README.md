# LibraryMangementSystem 

A simple, beginner‑friendly Django project for managing books, members, and borrow/return transactions. This README walks you through installing Python and Django, setting up a virtual environment, creating the project/app, running the server, and using the admin site—on both Windows and macOS.


✨ Features

Manage Books (title, author, ISBN, quantity, category)

Manage Members (name, email, phone, join date)

Track Transactions (issue and return dates, status)

Django Admin dashboard for CRUD operations

## Check versions:

```bash

## 🚀 Quick Start (Windows & macOS)

### 1) Clone or download this repository

https://techvidvan.com/tutorials/python-library-management-system/

### Install dependencies

```bash
pip install 

# If no requirements.txt yet:
pip install django
```


### Run the development server

```bash
# Windows & macOS
python manage.py runserver
